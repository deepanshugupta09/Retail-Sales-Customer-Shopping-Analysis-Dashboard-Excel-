# 📊 Customer Shopping Analysis Dashboard (Excel)

## Project Overview

This project is an interactive Excel dashboard developed to analyze customer shopping behavior, sales performance, and revenue trends. The dashboard transforms raw sales data into meaningful business insights through data cleaning, analysis, visualization, and reporting.

The goal of this project is to demonstrate Excel-based MIS reporting and analytical skills commonly required for MIS Analyst, Data Analyst, and Reporting Analyst roles.

## Business Problem

Businesses generate large amounts of sales data, but raw data alone does not provide actionable insights.

This project aims to:

- Track sales performance.
- Analyze customer purchasing patterns.
- Identify top-performing products and categories.
- Monitor revenue trends over time.
- Support business decision-making through visual reporting.

---

## Dataset Information

The dataset contains customer order information, including:

- Order Date
- Delivery Date
- Product Category
- Product Name
- Occasion
- City
- Revenue
- Order Details

---

## Project Workflow

### 1. Data Cleaning
- Removed inconsistencies and duplicate records.
- Standardized date formats.
- Checked for missing values.
- Organized raw data for analysis.

### 2. Data Transformation
- Created calculated fields.
- Structured data for Pivot Table analysis.
- Applied appropriate formatting.

### 3. Data Analysis
Analyzed:

- Revenue by Occasion
- Revenue by Category
- Revenue by Order Time
- Revenue by Month
- Top Products by Revenue
- Top Cities by Orders
- Customer Spending Trends

### 4. Dashboard Development
Created an interactive dashboard using:

- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Dynamic Filters

## Key Insights

### Revenue by Occasion
- Anniversary and Raksha Bandhan generated high revenue.
- Birthday and Valentine's Day contributed significantly to sales.

### Revenue by Category
- Colors category generated the highest revenue.
- Soft Toys and Sweets were among the top-performing categories.

### Monthly Trends
- Peak sales observed during February and August.
- Seasonal demand patterns are visible throughout the year.

### Top Products
- Identified highest revenue-generating products for inventory planning.

### Top Cities
- Certain cities contributed significantly more orders than others, helping identify high-demand regions.
